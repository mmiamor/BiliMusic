# 空间唱片 UI 方案

本方案仅用于独立交互原型，生产界面保持现状。以纸白背景、墨色文字和赭红强调色建立连续空间，取消包围各区的卡片边框；用留白、轻阴影与层级区分内容。唱片采用 CSS 透视，默认轻微倾斜，桌面指针跟随最多偏转 5°；歌词和控件保持正面，保证可读性。

桌面始终保留同一张唱片、歌词容器和底部播放控制。队列、DSP 沿右侧展开，唱片缩小并向左让位，不叠加模态遮罩；两种工具互斥，返回时保留播放位置、选中歌曲与触发按钮焦点。原型的 Esc 收起工具，音频连续。

正式接入时，歌词只突出当前行，手动滚动暂停跟随四秒，点按歌词立即定位；动画不延迟播放命令。原型使用内置器乐试听，默认如实显示没有歌词；可打开明确标注的歌词排版演示，检查逐句过渡。

动效分层：按钮反馈 120–200ms，工具展开 260–320ms，歌词过渡 400–500ms，视野切换 600–800ms；使用减速曲线，不用弹簧回摆。切换可中断，从当前视觉位置接续。唱片仅在真实 playing 状态缓慢匀速旋转；启动约一秒接近匀速，暂停约 1.2 秒内停稳，保留停止时的角度。旋转速度不随音量、DSP 或音质改变。

移动端采用单列，唱片、歌词、工具共用主内容区，底部控制固定。通过可见按钮切换，不依赖滑动手势；工具占满可用高度并独立滚动。触控关闭指针倾斜，3D 深度减半。长标题、键盘弹出和安全区不得挤出播放按钮。

实现优先使用 transform、opacity，仅在交互时更新，避免逐帧布局、全屏模糊与 WebGL。目标 60fps、每帧脚本低于 2ms，同时运动的合成层不超过三个，封面最长边 1024px。原型在连续两秒的帧间隔偏高时关闭透视跟随；窗口隐藏、离屏或暂停时停止装饰更新。减少动态设置禁用旋转、透视跟随与空间位移，保留即时切换和清晰焦点。

原型的 FLAC / 44.1 kHz 与实际内置音频一致，3D 表现不充当音频计量或 Hi-Res 认证。DSP 面板明确标为曲线预览，不处理试听音频；正式接入时使用现有 DSP 引擎与真实计量。上述性能值是实施预算，尚未作为跨设备基准测试结果。
