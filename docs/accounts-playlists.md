# 音乐账号、数据库与歌单

0.4.0 的网页版在进入音乐库前显示站点登录。音乐账号与哔哩哔哩授权是两种会话：前者管理自己的歌单，后者决定平台可播放的音轨与音质。哔哩哔哩登录仍位于设置页。

## SQLite

`users` 保存账号及 scrypt 密码派生值；`auth_sessions` 只保存随机会话令牌的 SHA-256；`playlists` 与 `playlist_tracks` 保存歌单、规范音源标识、展示信息和顺序。没有保存可过期的音频直链、请求头或平台凭据。

数据库路径优先级是 `BILIMUSIC_DB_PATH`、`BILIMUSIC_STATE_DIR`、`STATE_DIR`。默认只适合本地开发；生产应配置到服务的持久数据目录，独立于版本发布目录。SQLite 使用 WAL、外键与参数化语句。备份时使用 SQLite 一致性备份，不能只复制正在写入的主数据库而忽略 WAL。

首次启动通过环境变量初始化管理员，默认账号名为 `Music`，不会内置默认密码。可传 `BILIMUSIC_ADMIN_PASSWORD` 或格式为 `scrypt$盐$派生值` 的 `BILIMUSIC_ADMIN_PASSWORD_HASH`。已存在账号时，初始化配置不会覆盖它。私有环境文件、数据库、会话与备份不进入仓库或公开安装包。

## 会话与权限

- 浏览器会话采用 HttpOnly、SameSite 与 HTTPS Secure Cookie；登录轮换令牌，退出撤销会话。
- 登录按地址及账号限流；未登录无法调用音乐数据、播放代理、歌单或管理员 API。
- 每份歌单归当前账号所有。猜测另一个账号的歌单 ID 不能读写，普通成员不能调用管理员接口。
- 管理员在设置中的“数据库管理”查看账号/歌单/曲目/会话数量，并添加成员或管理员。页面不提供任意 SQL 执行。
- 退出音乐账号同时清除该站点会话关联的哔哩哔哩媒体授权。平台 Cookie 不返回浏览器页面。

## 歌单

从侧栏或移动端资料库进入“我的歌单”，创建名称与描述。在曲目详情选择“加入歌单”，可加入已有歌单或直接新建。歌单支持播放全部、收录当前队列、修改名称/描述、上移/下移、移除歌曲和确认删除。

每个账号最多 100 个歌单，每单最多 500 首；同一音源与投稿分 P 的重复曲目只保留一次。整单播放使用独立队列副本，随后整理歌单不会改变正在播放的队列。

网页版歌单保存在数据库，可随账号跨设备读取；原生应用歌单保存在本机。收藏与最近播放仍是设备数据，网页版按音乐账号分开存储。这一版没有静默上传旧收藏，也没有让原生应用自动连接某个线上账号。
