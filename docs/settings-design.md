# 设置与账号

0.3.3 将账号入口集中到侧栏“设置”。搜索页的“账号与登录”和 Hi-Res 发现提示也进入同一页面。手机宽度下，底栏提供“设置”标签。

设置页使用单栏分组，暂时收起右侧播放详情，底部播放控制保持可用；离开设置后恢复原布局。账号、播放、关于三组使用浅色卡片、细分隔线和静态控件，遵循已有的无动画风格。Windows 窗口按钮位于右上角，关闭按钮最靠右。

## 哔哩哔哩账号

- 进入设置时查询官方账号状态；尚未确认、检查中、已登录、未登录、查询失败分别显示。
- 确认未登录后提供官方登录入口。Windows 打开隔离于应用页面的官方登录窗口，沿用应用的持久会话；PWA 使用已有官方扫码授权，iOS 沿用原生登录桥接。
- 登录窗口关闭仅代表交互结束，应用再次查询状态后才展示登录成功。取消登录不会清空发现缓存或重播音乐。
- 查询失败保留上次确认的名称，并标注“上次确认”；重试成功前不提供基于旧状态的退出操作。
- 登录、退出、刷新期间复用进行中的操作，避免重复打开登录窗口或重复退出。
- 确认账号发生变化后，失效 B 站音质证据与发现缓存，当前播放或加载中的 B 站音轨重新解析。旧请求无法覆盖新账号的播放结果。
- 酷我、网易云等其他音源当前没有应用内账号登录，不显示不可用的登录按钮。

## 播放偏好

“默认发现分类”保存到本机，下一次启动采用选择的分类；默认仍为“Hi-Res 优先”。储存不可用时给出提示，不阻止页面使用。

DSP 开关沿用播放器的音效配置，旁通不会删除均衡器、前级或限幅参数，也不改变播放器音量。设置页与调音台、侧栏状态同步。控件提供可见键盘焦点，窄屏按纵向排列。

Windows 原生版在本次检查中运行；PWA 仅执行无服务的回归测试，iOS 未做真机验收。
