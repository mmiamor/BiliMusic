# DSP 调音台重建

0.4.0 从同一工作区原 Apple Music HiFi 的参数处理模型、RBJ 滤波器数学、Crossfeed、声道矩阵和 AudioWorklet 移植。BiliMusic 保留自身的单一媒体元素、异步音轨解析、备用音源与手机手势解锁逻辑。

界面分为概览、均衡器、效果、输出四页；独立调音台和完整播放器内共用同一组件。频响曲线只在参数变化时更新，没有装饰动画；概览中的数值来自正在运行的音频引擎。

| 模块 | 能力 |
| --- | --- |
| 参数 EQ | 最多 24 段；峰值、低/高架、低/高通、陷波、带通；10–22000 Hz、±24 dB、Q 0.1–24。支持数值编辑、节点拖动、滚轮调 Q、双击曲线添加。 |
| 预设 | 原版 12 组内置预设；个人预设保存/恢复/删除。删除个人预设保留当前音效参数。 |
| AutoEQ/APO | 粘贴或读取 ParametricEQ.txt，导入前显示文本；有错误时整批拒绝，不悄悄省略不支持的处理。导出提供文本与下载。 |
| 前级 | 手动 −24～+12 dB；自动按 EQ 响应的最大提升量估计衰减。导入手动前级时关闭自动模式。 |
| Crossfeed | 三组原版预设，300–1200 Hz 截止频率、1–15 dB 馈送衰减与 0.27 ms 交叉延迟。 |
| 声道 | 0–200% 宽度、左右平衡、单声道、左右交换和单侧反相。 |
| 限幅 | 1.5 ms 前视、立体声联动的样本峰值限幅，−6～0 dBFS 天花板、20–500 ms 释放。 |
| 计量 | DSP 前/后计量，左右峰值/RMS、相关度、削波数、LUFS、LRA 与 4 倍过采样真峰值估计；没有有效测量时显示空值。 |
| 输出 | 能力允许时选择设备；保存引擎采样率与缓冲策略，重新加载后生效。显示实际引擎采样率、延迟和处理链。 |

关闭的处理级从链路中移除。总旁通保留 BiliMusic 主音量，避免旁通时音量突然跳变。旧版十段参数转为 PK/Q=1.41，保持原前级、音量和开关，不自动启用新 Crossfeed 或声道变换；旧配置的自动前级默认关闭。

非标准 Q 的架式滤波采用 RBJ IIR；低通/高通的 Web Audio Q 使用对应的 dB 表示。有效频率最终受实际采样率限制。参数变化保留短音频平滑以减轻拉链噪声，与 UI 动画无关。

AudioWorklet 失败时明确显示兼容模式，使用 Compressor 和有限的峰值/RMS 计量；不能把兼容模式称为同样的前视限幅或完整 LUFS 测量。真峰值是计量估计，限幅器处理样本峰值。自动前级仅估计 EQ 增益，不保证声道加宽等处理之后绝不削波。应用仍通过系统音频输出，不宣称硬件独占或 bit-perfect。
